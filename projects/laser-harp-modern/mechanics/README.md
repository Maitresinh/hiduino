# Mécanique et réemploi

Le dépôt Cybercraftics publie un dossier `3d_printables` sous licence MIT :

https://github.com/cybercraftics/laser_harp/tree/main/3d_printables

Ses pièces concernent une version à moteur pas-à-pas. Réutiliser uniquement les éléments génériques après contrôle des dimensions : boutons, serre-câbles, supports de capteur et certains colliers. Le support moteur n'est pas adapté au galvo.

## Pièces nouvelles minimales

- `laser_clamp.scad` : collier paramétrique ;
- `opt101_hood.scad` : tube anti-lumière pour le module reçu ;
- `galvo_adapter_plate.scad` : plaque plate à modifier après mesure du bloc galvo.

Aucun capot prétendument sûr n'est fourni avant connaissance des dimensions et du chemin optique. Une pièce opaque mal dessinée peut simplement cacher le danger au lieu de le supprimer.
