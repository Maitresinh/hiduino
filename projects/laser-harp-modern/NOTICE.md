# Crédits et réutilisation

Ce dépôt est une reconstruction indépendante fondée sur l'étude de plusieurs projets publics.

- **M1r3o/Laser-Harp-Project** : principe de harpe ouverte à galvo, blanking, positions discrètes et détection synchronisée. Certains fichiers firmware portent une licence CC BY-NC-SA 2.0 BE. Aucun code, Gerber ou schéma de ce dépôt n'est redistribué ici.
- **Trasselfrisyr/laserharp** : usage de Teensy et USB-MIDI, hystérésis et tables de gammes. Aucune licence globale n'a été trouvée lors de l'audit, donc aucune portion de code n'est copiée.
- **Evanthx/laserharp** : séparation de la logique et tests unitaires. Aucune portion de code n'est copiée.
- **cybercraftics/laser_harp** : mesure de distance pour modifier la hauteur, pièces 3D et documentation. Dépôt sous licence MIT. Le présent projet reprend le concept de quantification de distance, mais remplace les lectures ultrasoniques bloquantes par un capteur ToF non bloquant.
